## От теории к production

Теперь, когда заложен прочный фундамент в области information retrieval, пришло время перенести всю эту теорию в production. Большинство техник извлечения, рассмотренных ранее, можно реализовать с помощью традиционной реляционной базы данных, но как только требуется искать по миллионам или даже миллиардам документов, некоторые операции — в частности, векторные операции, лежащие в основе semantic search — начинают значительно замедляться.

В этот момент, вероятно, потребуется перейти на `vector database`. `Vector database` — база данных, оптимизированная для хранения и поиска по огромным объёмам векторных данных, и в результате они стали почти синонимом RAG-систем.

## Содержание модуля

В этом модуле рассматривается:

- почему vector database настолько оптимизированы для векторного извлечения;
- практическая работа с vector database для выполнения разнообразных видов поиска;
- набор техник, используемых в production RAG-системах, таких как chunking документов, query parsing и re-ranking, которые применяются в production-окружениях для дальнейшего улучшения производительности retriever.

Как и всегда, в конце модуля будет программное задание (programming assignment), чтобы применить все эти концепции.

## Заключение

Модуль позволяет применить все накопленные знания по information retrieval на практике.
