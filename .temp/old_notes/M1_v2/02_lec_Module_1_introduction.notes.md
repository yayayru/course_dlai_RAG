# Module 1 introduction

## Источники

- Основной источник: `02_lec_Module_1_introduction.trans.txt`.
- Дополнительный источник для сверки терминов и структуры: `slides_M1.pdf`.

## Назначение модуля

Модуль 1 задает базовый blueprint для построения мощной `RAG`-системы.

В этом модуле нужно:

- изучить foundational `RAG` concepts;
- познакомиться с главными компонентами `RAG`-системы;
- начать строить функциональную `RAG`-систему.

## Темы модуля

Сначала модуль дает high-level introduction to `RAG`:

- что такое `RAG`;
- зачем его использовать;
- как он может улучшить качество ответов, которые генерирует `LLM`.

Затем модуль переходит к архитектуре `RAG`-системы.

> **Определение:** `retriever` — компонент `RAG`-системы, который помогает `LLM` находить релевантную информацию в `knowledge base` с trusted information.

`RAG` соединяет:

- `LLM`;
- `retriever`;
- `knowledge base` trusted information.

В модуле обещан deep dive по каждому компоненту и затем объяснение того, как эти компоненты работают вместе.

## Примеры применения

Поскольку `RAG` полезен в широком наборе контекстов, в модуле будут показаны несколько примеров production `RAG` systems.

После этих примеров учащийся должен начать думать о возможностях применения `RAG` в собственных `LLM`-based projects.

## Практическая часть

На протяжении модуля предусмотрена работа с sample code.

В конце модуля нужно выполнить первую programming assignment:

- реализовать части простой `RAG`-системы;
- начать с базовой системы, которая затем будет расширяться в следующих модулях.

## Как система будет развиваться дальше

В следующих частях курса первая система будет усложняться.

К ней будут добавляться:

- более robust `retriever`;
- `vector database`;
- более sophisticated uses of an `LLM`;
- техники monitoring;
- техники evaluation.

## Итог лекции

Модуль 1 задает roadmap для всего курса. Он начинается с foundational concepts, затем показывает архитектуру и применение `RAG`, после чего переводит материал в практическую реализацию простой системы.
