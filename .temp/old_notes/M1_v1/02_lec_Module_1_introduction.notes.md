## Назначение модуля

Module 1 начинается с идеи blueprint: чтобы построить powerful RAG system, нужно начать с общего плана.

В этом модуле слушатель должен:

- изучить foundational RAG concepts;
- познакомиться с main components RAG system;
- начать building a functional RAG system.

## Последовательность тем в модуле

Сначала дается high-level introduction to RAG:

- что такое RAG;
- зачем использовать RAG;
- как RAG может improve the quality of responses generated by a large language model.

Затем модуль переходит к architecture of a RAG system.

## Основные компоненты RAG system

RAG pairs an LLM with a retriever.

Retriever описан как component, который помогает LLM find relevant information in a knowledge base of trusted information. В модуле предполагается deep dive по каждому компоненту и затем разбор того, how they work together.

## Production examples и применение в собственных проектах

RAG useful in a wide variety of contexts. Поэтому в модуле будут приведены examples of production RAG systems.

После этого слушателю предлагается начать reflecting on opportunities to use RAG in your own LLM-based projects.

## Hands-on часть и programming assignment

Throughout the module слушатель будет работать с sample code.

В конце модуля предусмотрено первое programming assignment: implementing parts of a simple RAG system.

## Как первый RAG system будет развиваться дальше

В течение остальной части курса первый system будет расширяться. В него будут добавлены более complex features:

- robust retriever;
- vector database;
- more sophisticated uses of an LLM;
- techniques for monitoring and evaluation.
